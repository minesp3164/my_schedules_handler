# 포인트 해금 보상 기획안

작성일: 2026-09-14
목적: 포인트를 단순한 점수가 아닌, 응원·회복·성장 기록으로 이어지는 열쇠로 사용한다.

## 기본 원칙

- 포인트는 차감하지 않는다. 누적 포인트 또는 기간 내 달성 점수로 해금한다.
- 보상은 사용자를 더 오래 일하게 만드는 장치보다, 쉬고·돌아보고·다시 시작하게 돕는 경험이어야 한다.
- 경쟁, 랭킹, 좋아요, 답장 기능은 초기 범위에서 제외한다.
- 해금 기준은 부담스럽지 않게 시작하고, 실제 사용 데이터에 따라 조정한다.

## 해금 보상 5종

### 1. 익명 응원 메시지 보내기

다른 취업 준비 사용자에게 짧은 응원 메시지를 남길 수 있는 작성 권한을 해금한다.

| 항목 | 내용 |
| --- | --- |
| 해금 기준 예시 | 주간 100점 달성 시 1개 |
| 사용 흐름 | 목표 달성 → `응원 남기기` → 문구 작성 → 서버 검토 → 익명 메시지 풀 등록 |
| 제한 | 100자 내외, 링크·연락처·개인정보 입력 불가 |
| 수신 UX | 목표 달성·회복 모드·집중 시작 전, 하루 최대 1회 응원 카드 노출 |
| 수신 액션 | `숨기기`, `신고` |

#### 안전 정책

- 작성 중 전화번호, 이메일, URL, SNS 아이디 패턴을 차단한다.
- 욕설, 혐오, 성적 표현, 위협 문구를 클라이언트와 서버에서 모두 검사한다.
- 신고된 메시지는 즉시 수신 목록에서 숨기고 검토 상태로 전환한다.
- 발신자·수신자 정보와 답장 기능은 노출하지 않는다.

### 2. 회복 패스

부담이 큰 날, 오늘의 목표 하나를 실패 처리하지 않고 다음 날로 옮길 수 있는 권한이다.

| 항목 | 내용 |
| --- | --- |
| 해금 기준 예시 | 누적 200점마다 1회 |
| 사용 흐름 | 오늘의 할 일 메뉴 → `내일로 옮기기` → 회복 패스 사용 확인 |
| 효과 | 해당 항목을 오늘의 전체 목표 판정에서 제외하고, 다음 날 루틴에 보관 |
| 기록 | 해당 일은 `회복 선택`으로 표시하며 실패·벌점으로 표현하지 않음 |

#### 주의점

- 목표 자체를 삭제하지 않는다.
- 너무 자주 쓰이지 않도록 보유 가능 수를 제한한다.
- 마감이 있는 실제 지원처럼 특정 종류의 할 일에는 사용을 제한할 수 있다.

### 3. 주간 회고 열기

이번 주의 행동을 수치와 짧은 질문으로 돌아보고, 다음 주 첫 행동을 정한다.

| 항목 | 내용 |
| --- | --- |
| 해금 기준 예시 | 한 주 300점 달성 |
| 제공 내용 | 집중 시간, 실제 지원 수, 알고리즘·포트폴리오 기록, 완료한 목표 수 |
| 회고 질문 | `이번 주 가장 잘한 한 가지는?`, `다음 주 가볍게 시작할 일은?` |
| 결과 | 한 장의 주간 회고 카드로 보관 |

#### UX 원칙

- 지난주와의 점수 경쟁보다, 이번 주 실제로 쌓은 행동을 우선 보여준다.
- 회고를 건너뛰어도 불이익을 주지 않는다.

### 4. 미래의 나에게 응원 남기기

현재의 사용자가 미래에 지치거나 중요한 순간을 맞을 자신에게 짧은 편지를 남긴다.

| 항목 | 내용 |
| --- | --- |
| 해금 기준 예시 | 누적 400점 달성 |
| 작성 예시 | `오늘 한 번 시작한 것만으로 충분해. 다시 천천히 해보자.` |
| 노출 시점 | 회복 모드 진입, 면접 준비일, 중요한 마일스톤 달성 시 |
| 노출 빈도 | 같은 편지는 일정 기간 재노출하지 않음 |

#### UX 원칙

- 메시지는 기본 비공개이며 작성자 본인에게만 노출한다.
- 카테고리 선택을 지원한다. 예: `지친 날`, `면접 전`, `지원 결과를 기다릴 때`.

### 5. 성장 기록 카드 저장

한 달 또는 특정 마일스톤에서 쌓은 노력을 한 장의 카드로 보관한다.

| 항목 | 내용 |
| --- | --- |
| 해금 기준 예시 | 누적 500점 또는 월간 목표 달성 |
| 카드 내용 | 집중 시간, 실제 지원 수, 완료 일수, 대표 마일스톤, 내가 남긴 한 줄 회고 |
| 사용처 | 앱 안 보관함, 이미지 저장, 나중에 취준 기록 회고 |

#### 예시

> 2026년 9월의 기록
> 집중 12시간 · 실제 지원 8건 · 전체 목표 달성 17일
> 작은 기록을 계속 쌓아 온 한 달

## 권장 초기 해금 규칙

| 보상 | 기준 | 횟수 |
| --- | ---: | --- |
| 익명 응원 메시지 보내기 | 주간 100점 | 주 1개 |
| 회복 패스 | 누적 200점 | 최대 1개 보유 |
| 주간 회고 열기 | 주간 300점 | 주 1회 |
| 미래의 나에게 응원 남기기 | 누적 400점 | 1회 해금 후 상시 작성 가능 |
| 성장 기록 카드 저장 | 누적 500점 또는 월간 목표 | 월 1장 |

## 권장 출시 순서

1. 익명 응원 메시지 보내기: 안전 필터·신고·숨김을 함께 구현한다.
2. 주간 회고 열기: 이미 있는 기록 데이터를 활용해 빠르게 제공한다.
3. 미래의 나에게 응원 남기기: 개인적이고 차별화된 회복 경험을 만든다.
4. 성장 기록 카드 저장: 월간 데이터와 이미지 저장 흐름을 추가한다.
5. 회복 패스: 일일 목표와 보상 계산 규칙에 영향을 주므로 마지막에 신중하게 도입한다.
