## 1. 콘셉트 & 타깃

**한 문장 가치 제안**: "금요일 오후 30분의 보고서 작성을 5분으로."

한 주치 GitHub 활동(커밋·PR·이슈)과 캘린더 회의를 모아, 퇴근 전에 완성된 주간 보고서 초안을 받아 가는 개인 도구입니다. 사용자는 초안을 다듬어 원하는 곳에 붙여넣거나 슬랙으로 발송합니다.

### ICP (v2 — 좁힘)

**"회사·클라이언트에 정기적으로 서면 주간 보고를 제출해야 하는 개인 개발자"**
(외주·프리랜서, 에이전시 소속, 엔터프라이즈 원격 개발자)

보고 의무가 없는 개발자는 제품을 쓰지 않으므로 초기 타깃에서 제외합니다. B2C 구독 모델은 유지하되, "보고서를 반드시 써야 하는 사람"만을 위한 제품으로 메시지를 좁힙니다.

### 차별화 방어

경쟁은 "GitHub 활동을 ChatGPT에 붙여넣기" 같은 무료 대안입니다. 차별점은 요약 문구가 아니라:

- **주간 비교**: 지난주 대비 완료·이슈 추이 문장 자동 생성
- **누적 히스토리**: 매주 쌓이는 보고서가 개인 성과 기록이 됨
- **자동화**: "매주 금요일, 보고서가 미리 써져 있음" — 신뢰가 쌓인 뒤에 활성화

## 2. 핵심 사용 시나리오

1. GitHub으로 가입 → **GitHub App 설치**(읽기 권한, 저장소 선택)
2. 최근 7일 활동으로 **즉시 백필 초안 생성** — 첫 세션에서 가치 확인 (v2 추가)
3. 구글 캘린더 연결(선택) — 수집 항목(회의 제목 포함 여부)을 사용자가 선택 (v2: 옵트인 + 마스킹 기본)
4. 주간 화면(월~일)에서 활동 타임라인 확인
5. **"초안 생성"** → AI가 3개 섹션 작성: *이번 주 완료 / 다음 주 계획 / 이슈·블로커* + 지난주 대비 비교
   - 처음 2~3회는 수동 생성. 사용자가 품질을 수용한 뒤에만 자동 초안 활성화 (v2 추가)
6. 편집기에서 수정 → 마크다운 복사·다운로드 또는 슬랙 웹훅 발송
7. 금요일 오후 리마인더 + 주중 무기록 시 점검 알림 (v2: 주중 리텐션 풀 추가)

## 3. MVP 범위

### 포함

| 항목 | 비고 |
|---|---|
| GitHub App 연동 | 최소 읽기 권한, 저장소 선택 |
| 활동 수집 | 커밋·PR·이슈 (GraphQL) |
| 구글 캘린더 연동 | 최소 스코프, 제목 수집 옵트인 (M2 후반 배치) |
| AI 초안 + 지난주 비교 | 첫 2~3회 수동 생성 |
| 편집기 | 마크다운 소스 오브 트루스 |
| 내보내기 | 마크다운 복사·다운로드, 슬랙 웹훅 |
| 주간 자동 초안 | 수동 수용 후 활성화 |
| 리마인더 | 금요일 + 주중 무기록 점검 |
| 온보딩·랜딩 | 1주차 수요 검증과 병행 |

### 제외 (Phase 2+)

팀 기능, Notion·Jira 연동, 이메일 발송, 모바일 앱, Stripe 결제(베타 반응 확인 후).

## 4. 데이터 모델

- `users` — 계정, 주간 기준(월~일), 리마인더 설정, 자동 초안 활성화 여부
- `connections` — GitHub App 설치 / Google / Slack 연결 — **전부 암호화 저장**
- `repositories` — 연결된 저장소, 수집 상태
- `activity_events` — 커밋·PR·이슈·회의 정규화 단일 스트림. 인덱스: `(week_key, user_id, occurred_at)` (v2: Neon 파티션은 제거, 단순 인덱스로)
- `calendar_events` — Google event ID 기준, 상태(취소·변경) 조정용 (v2 추가)
- `reports` — 주차별: 활동 스냅샷(캘린더 항목은 짧은 TTL), 생성 초안, 최종 편집본 (버전 행으로 관리)
- `job_runs` — 백그라운드 작업 멱등성·재시도 관리, 유니크 제약 `(job, week_key)` (v2 추가)
- `send_attempts` — 슬랙 발송별 시도 기록과 응답 (v2 추가)

## 6. 개인정보·보안 원칙 (v2 신설)

1. **데이터 최소화**: 캘린더는 `calendar.events.readonly` 스코프만, 회의 제목은 기본 마스킹, 사용자가 명시 옵트인한 항목만 수집
2. **AI 전송 통제**: 마스킹된 필드만 전송, 원본 스냅샷은 짧은 TTL 삭제
3. **토큰 보안**: 모든 연동 토큰은 암호화 저장, GitHub은 짧은 수명 토큰만 유지
4. **사용자 통제**: "내 데이터 전체 삭제" 흐름 필수(GitHub/Google 앱 심사 요건이기도 함)
5. **일정 반영**: 개인정보처리방침·약관 게시를 1주차로 앞당기고 Google OAuth 검증을 조기 신청

## 7. 수익화 (Phase 2)

- **무료**: 저장소 1개, 주 1회 보고서, 히스토리 4주, 수동 생성만
- **유료 월 $7**: 무제한 저장소, 포맷 커스텀, **자동 초안·자동 발송**, 무제한 히스토리
- 페이월 논리: "AI가 써줌"이 아니라 **"매주 자동으로 쌓임"** 을 유료 가치로
- 베타 기간에 가격 fake-door 테스트($7 사전 약속)로 지불 의사 검증
