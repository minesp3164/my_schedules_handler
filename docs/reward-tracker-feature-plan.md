# 리워드 트래커 기능 개선안

작성일: 2026-09-13  
목적: 취업 준비 루틴을 더 쉽게 시작하고, 기록·보상을 실제 행동으로 연결한다.

## 제품 원칙

- 실패나 공백을 벌주지 않고, 다시 시작할 수 있는 작은 행동을 제안한다.
- 포인트는 단순 수치가 아니라 사용자가 원하는 휴식과 보상으로 이어져야 한다.
- 반복 루틴은 빠르게 기록하고, 일회성 활동도 잃지 않게 한다.

## 도입 기능

### 1. 오늘의 추천 다음 행동

현재 점수, 남은 목표, 시간대에 맞춰 지금 바로 할 수 있는 행동 하나를 홈에 제안한다.

#### 사용자 경험

- 홈 상단 또는 보상 진행도 카드에 한 개의 추천 행동을 표시한다.
- 예: `보상까지 10점 남았어요. 10분 집중을 시작해볼까요?`
- 예: `오늘 첫 기록이에요. 알고리즘 1문제부터 가볍게 시작해 보세요.`
- 사용자는 `시작하기`, `다른 제안 보기`, `오늘은 숨기기`를 선택할 수 있다.

#### 추천 규칙 초안

| 상황 | 추천 |
| --- | --- |
| 오늘 활동이 없음 | 5분 또는 10분 집중 시작 |
| 보상까지 남은 점수가 적음 | 남은 점수를 채울 수 있는 가장 짧은 할 일 |
| 목표를 일부 완료함 | 진행 중인 할 일 1회 추가 완료 |
| 오후·저녁이며 미완료 목표가 있음 | 부담이 가장 적은 미완료 목표 |
| 모든 목표를 완료함 | 보상 확인 또는 내일 루틴 준비 |

#### 구현 메모

- 초기에는 서버 AI 없이 규칙 기반으로 구현한다.
- 대시보드 응답의 `tasks`, 일일 점수, 보상 목표, 첫 활동 시각을 이용한다.
- 사용자가 숨긴 제안은 당일 다시 노출하지 않는다.

### 2. 하루 마감 리캡

하루를 마칠 때 오늘의 성취를 짧게 되돌아보고, 다음 날의 첫 행동을 정한다.

#### 사용자 경험

- 설정한 시간 또는 마지막 활동 후 홈에서 리캡 카드를 보여준다.
- 예: `오늘 65점 · 집중 50분 · 완료 3개. 가장 많이 해낸 일은 포트폴리오 개선이에요.`
- `내일 첫 행동 정하기`에서 할 일 하나 또는 5분 집중을 고른다.
- 다음 날 홈에서 선택한 첫 행동을 우선 노출한다.

#### 포함 정보

- 오늘의 총점, 완료한 할 일 수, 집중 시간
- 달성한 보상 또는 보상까지 남은 거리
- 가장 많이 진행한 활동
- 내일 첫 행동

#### 구현 메모

- 리캡은 활동이 있는 날에만 표시한다.
- 계획을 정하지 않아도 닫을 수 있도록 하고, 미설정에 불이익을 주지 않는다.
- 초기에는 앱 내 카드로 시작하고, 반응이 좋으면 저녁 푸시 알림으로 확장한다.

### 3. 보상 사용 기록

해금된 보상이 실제 휴식과 만족으로 이어지도록 보상 수령·사용 상태를 관리한다.

#### 사용자 경험

- 보상 달성 후 `보상 받기`를 누르면 해금 보상 목록에 추가된다.
- 목록에서 `나중에 사용할게요` 또는 `사용했어요`를 선택한다.
- 예: `이번 주 300점 보상: 좋아하는 카페에서 커피 마시기`
- 이미 사용한 보상도 기록으로 남겨, 노력과 보상의 연결을 확인한다.

#### 데이터 초안

| 필드 | 설명 |
| --- | --- |
| reward_achievement_id | 원본 보상 달성 기록 |
| status | unlocked, redeemed, skipped |
| redeemed_at | 실제 사용 시각 |
| note | 보상에 대한 짧은 메모, 선택 사항 |

#### 정책

- 보상은 포인트를 차감하지 않는다. 이미 달성한 성취를 실제로 누렸다는 기록이다.
- 사용하지 않은 보상은 만료시키지 않는다.
- 사용자는 보상 문구를 직접 수정할 수 있다.

### 4. 마일스톤 배지

일별 점수와 별개로 장기 성취를 눈에 보이게 기록한다.

#### 초기 배지 예시

| 영역 | 기준 | 예시 이름 |
| --- | ---: | --- |
| 누적 전체 목표 달성 | 10일 / 30일 / 100일 | 첫 10일, 꾸준한 한 달, 100일의 발자국 |
| 집중 | 10시간 / 50시간 / 100시간 | 첫 10시간, 몰입의 시간 |
| 실제 지원 | 5건 / 20건 / 50건 | 첫 지원 5건, 기회의 문을 열다 |
| 알고리즘 | 10문제 / 50문제 / 100문제 | 문제 해결가 |
| 포트폴리오·이력서 | 10회 / 30회 | 다듬고 또 다듬기 |

#### 사용자 경험

- 새 배지 해금 시 작은 축하 화면과 함께 어떤 행동으로 달성했는지 보여준다.
- 기록 화면에 `나의 발자국` 섹션을 추가한다.
- 미달성 배지는 압박을 주지 않도록 기본 화면에서 숨기고, 원할 때만 전체 목록을 본다.

#### 구현 메모

- 활동의 누적 합계를 기준으로 판정하며, 연속 기록이 끊여도 회수하지 않는다.
- 배지 규칙과 달성 기록을 분리해 향후 기준 추가·수정이 가능하게 한다.

### 5. 회복 모드

기록 공백 뒤에도 죄책감 없이 루틴으로 돌아올 수 있도록 목표와 안내를 가볍게 조정한다.

#### 진입 조건 초안

- 최근 3일 이상 활동이 없을 때 홈에서 한 번 제안한다.
- 사용자가 직접 설정에서 켜거나 끌 수도 있다.

#### 사용자 경험

- 예: `오랜만이에요. 오늘은 5분 집중 하나면 충분해요.`
- 회복 모드에서는 사용자가 선택한 1~2개의 작은 목표만 홈 첫 화면에 표시한다.
- `원래 루틴으로 돌아가기`를 언제든 선택할 수 있다.
- 회복 활동도 일반 포인트와 누적 성취에 정상 반영한다.

#### 주의점

- 공백 일수, 실패, 밀린 할 일을 강조하지 않는다.
- 자동으로 목표를 삭제하거나 포인트 규칙을 바꾸지 않는다.

### 6. 요일별 루틴과 템플릿 복제

평일·주말, 지원 준비일·회고일처럼 맥락이 다른 날의 할 일을 빠르게 전환한다.

#### 사용자 경험

- 루틴 세트를 만든다. 예: `평일 기본`, `지원 집중`, `주말 정리`.
- 각 세트에 적용 요일을 지정하거나, 해당 일만 일회성으로 적용한다.
- 기존 할 일은 `복제`해 제목·포인트·횟수만 수정할 수 있다.
- 오늘 적용된 루틴 이름을 홈에서 확인하고, 필요하면 다른 루틴으로 바꾼다.

#### 데이터 초안

| 엔터티 | 주요 값 |
| --- | --- |
| routine_templates | 이름, 적용 요일, 활성 여부, 정렬 순서 |
| routine_template_tasks | 루틴, 제목, 포인트, 목표 횟수, 종류, 정렬 순서 |
| task_template | 특정 날짜에 적용된 실제 할 일 템플릿 또는 루틴 연결 정보 |

#### 정책

- 오늘 이미 완료한 항목이 있으면 루틴 변경 전 경고하고, 완료 기록은 유지한다.
- 기존 단일 할 일 템플릿 사용자는 자동으로 `기본 루틴`으로 이전한다.

### 7. 중단 집중 세션 정리

오래 일시정지된 타이머를 방치하지 않도록 재개·종료 선택을 돕는다.

#### 사용자 경험

- 일시정지 후 일정 시간(예: 30분)이 지나면 홈과 집중 화면에 정리 카드를 표시한다.
- 예: `오전에 멈춘 25분 집중이 있어요. 이어서 할까요, 오늘은 마칠까요?`
- 선택지: `계속하기`, `이번 세션 마치기`, `나중에 결정`.
- 취소/종료해도 실패로 표현하지 않고, 기록에 `중단됨`으로 남긴다.

#### 구현 메모

- 이미 존재하는 `paused` 상태와 재개·취소 API를 활용한다.
- 자동 완료나 자동 취소는 하지 않는다.
- 앱을 다시 열었을 때와 푸시 권한이 있을 때만 부드럽게 안내한다.

## 권장 출시 순서

| 단계 | 기능 | 이유 |
| --- | --- | --- |
| 1 | 오늘의 추천 다음 행동, 중단 집중 세션 정리 | 기존 대시보드·타이머 데이터로 빠르게 제공 가능 |
| 2 | 하루 마감 리캡, 회복 모드 | 시작·복귀 경험을 직접 개선 |
| 3 | 요일별 루틴과 템플릿 복제 | 반복 입력을 줄이고 사용 패턴을 넓힘 |
| 4 | 보상 사용 기록, 마일스톤 배지 | 장기 동기와 보상 경험을 강화 |

## 성공 지표 초안

- 추천 행동을 본 뒤 10분 이내 첫 활동을 시작한 비율
- 활동 공백 3일 이상 사용자 중 회복 모드 후 7일 내 재활동 비율
- 일시정지 세션의 재개·정리 비율
- 해금 보상 중 `사용했어요`로 기록된 비율
- 주간 활성 일수와 누적 전체 목표 달성 일수
