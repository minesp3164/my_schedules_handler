# 디자인 시안 출처

다섯 시안은 아래 공개 템플릿의 **시각 방향만 참고해 새로 작성한 HTML**이다. 템플릿 원본 파일이나 이미지 자산을 복제하지 않았다.

| 시안 | 참고 템플릿 | 적용 방향 |
| --- | --- | --- |
| 01 | [Horizon AI Boilerplate](https://www.creative-tim.com/product/horizon-ai-boilerplate-nextjs-figma) · MIT | 밝은 AI 대시보드, 보라색 지표 카드 |
| 02 | [TaskFlow](https://dribbble.com/shots/26235938-Free-Figma-Dashboard-UI-Kit-TaskFlow) | 에디토리얼 생산성 도구, 오렌지 포인트 |
| 03 | [Themesberg Figma Admin Dashboard](https://github.com/themesberg/figma-admin-dashboard-template) · MIT | 정돈된 운영 대시보드, 정보 밀도 높은 화면 |
| 04 | [AI Chatbot & Assistant App UI Kit](https://titanui.com/129426-ai-chatbot-assistant-app-ui-kit/) | 모바일 AI 코치, 대화형 시작 흐름 |
| 05 | [Figma Dashboard templates](https://www.figma.com/templates/dashboard-designs/)의 Vision UI 계열 | 다크·글래스·그래디언트 기반 집중 화면 |

원본을 제품 코드에 직접 포함하려면 해당 페이지에서 각 템플릿의 최종 이용 조건과 저작자 표기 요건을 다시 확인한다.
