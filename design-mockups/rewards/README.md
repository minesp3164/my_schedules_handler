# 포인트 해금 보상 목업

포인트를 **소비하는 상점**이 아니라, 사용자가 쌓은 기록으로 회복·응원·성찰 경험을 **해금하는 보관함**으로 해석한 모바일 웹 목업입니다.

| 화면 | 파일 | 핵심 UX |
| --- | --- | --- |
| 1. 해금 보관함 | [reward-shop.html](reward-shop.html) | 포인트 잔액 대신 누적 기록과 해금 진행도를 보여 주는 상점 진입점 |
| 2. 익명 응원 | [cheer.html](cheer.html) | 100자 응원 작성, 안전 안내, 답장 없는 전달 구조 |
| 3. 회복 패스 | [recovery.html](recovery.html) | 오늘의 목표를 실패 없이 내일로 이동하는 확인 흐름 |
| 4. 주간 회고 | [reflection.html](reflection.html) | 점수 경쟁 대신 실제 행동과 다음 주 첫 행동을 기록 |
| 5. 나를 위한 기록 | [future.html](future.html) | 미래 편지와 월간 성장 카드 보관함 |

모든 화면은 외부 라이브러리 없이 열 수 있는 단일 HTML이며, 공통 스타일은 `reward-system.css`에 있습니다.
